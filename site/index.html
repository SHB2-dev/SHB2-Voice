テキストチャットを、
VOICEVOXの声で読み上げる。

VCに入ってチャットに書き込むだけ。ずんだもんなど、VOICEVOXのキャラクターの声でメッセージを読み上げるDiscord BOTです。最大6体が、それぞれ別のVCで同時に動きます。

1号機をサーバーに招待する

招待できるのは1号機です。2号機以降は、1号機の返信に出る招待URLから追加できます。

機能

できることをすべて紹介します。

VOICEVOXの声で読み上げ

VOICEVOXの公開APIを使い、100種類以上のキャラクター・スタイルから声を選べます。

声・速度・読み名は人ごとに設定

/voiceで声、/speedで速度(0.5〜2.0)、/nameで自分の読み上げ名を設定。全号機で共通に使われます。

最大6体で複数VCを同時に担当

/joinを打つと、空いている号機が自動で入ります。VCやBOTを引数で指定することもできます。

サーバー辞書

/dictで、サーバー独自の言葉の読み方を登録できます。みんなで共有され、すべての号機で使われます。

外部連携API

Lumi の大喜利など、ほかのBOTから、HTTPで読み上げを依頼できます。回答は、回答した人本人の声・速度で読みます。サーバーごとのトークンで認証し、/externalで管理します。

VC自動接続

/autojoinをオンにすると、/joinしなくても、誰かがVCに入った時点で空いている号機が自動参加。そのVCのチャットを読み上げます。

複数のチャンネルを読み上げ

コマンドを打ったチャンネルと、そのVC自身のチャットが読み上げ対象になります。/channelで追加・削除できます。

ステージチャンネル対応

ステージに入ると、権限があれば自動でスピーカーに。なければ挙手して、モデレーターの許可を待ちます。

入退出のアナウンス

VCに誰かが入ると「○○が参加しました」、出ると「○○が退出しました」と、本人の声と読み上げ名で知らせます。BOTの入退出も対象です。/announceで、サーバーごとにオフにできます。

号機の状況が一目で分かる

/joinや/statusで、各号機が空き(○)か使用中(✕)かが分かります。

未招待の号機は招待URLを案内

そのサーバーに入っていない号機があれば、名前と招待URLを自動で表示します。

誰もいなくなったら自動退出

VCから人間がいなくなると、BOTは自動で退出します。つけっぱなしの心配はありません。

読みやすい文に整形

URL、コードブロック、ネタバレ、絵文字、メンションを読みやすい形に置き換え、長文は途中で切ります。

応答速度のグラフ

/pingで、DiscordとVOICEVOX APIの応答速度を、直近のグラフ付きで表示します。

Webhookで定期レポート

管理者向けに、応答速度のグラフを30分おきにWebhookで送れます。

使い方

はじめて使うときの手順です。

  1. 1号機を招待する。 このページ上部のボタンから、サーバーに追加します。サーバーの管理権限が必要です。
  2. VCに入る。 読み上げてほしいボイスチャンネル(またはステージ)に、自分が先に入ります。
  3. チャットで/joinを打つ。 空いている号機がVCに入り、「読み上げ対象」のチャンネルを返信で知らせます。
  4. チャットに書き込む。 対象のチャンネルの発言が、自動で読み上げられます。
  5. 声を変える。 /voiceで好きなキャラクターを選べます。候補は入力しながら絞り込めます。
  6. 終わったら/leave。 何もしなくても、全員がVCから抜ければ自動で退出します。

号機の状況表示の例

１号機 ✕ (雑談) ２号機 ○ ３号機 －

○ 空き　✕ 使用中(入っているVC名つき)　－ このサーバーに未招待

号機の選ばれ方

1つのVCにつき担当は1体です。/joinでは、そのサーバーにいて、まだVCに入っていない号機のうち、番号の小さいものが入ります。2つ以上のVCで同時に使いたいときは、2号機以降をサーバーに招待しておいてください。

同じVC・同じチャンネルを、複数の号機が二重に読み上げることはありません。

読み上げのルール

メッセージは、読み上げる前に次のように整形されます。

元の内容読み上げ
URL(https://…)「ユーアールエル」
コードブロック(```…```)「コードブロック」
ネタバレ(||…||)「ネタバレ」
サーバー絵文字絵文字の名前
ユーザー・ロールのメンション「名前さん」(表示名で読みます)
チャンネルのメンション「名前チャンネル」
@everyone / @here「全員宛て」/「オンライン宛て」
長いメッセージ100文字で切り、「、以下略」を付けます(上限は管理者が変更できます)
サーバー辞書に登録した単語登録した読みに置き換えます(/dict)
BOTの発言読み上げません(外部連携API経由の依頼は、読み上げます)

読み上げ対象になるチャンネル

/joinを打ったチャンネルと、参加したVC(またはステージ)自身のテキストチャットです。そのほかのチャンネルは、/channel addで追加します。

必要なBOTの権限

チャンネルを表示、メッセージを送る、接続、発言、メンバーをミュート、スピーカー参加をリクエスト。最後の2つは、ステージチャンネルで発言権を得るために使います。招待リンクに、あらかじめ含まれています。

よくある質問

 

コマンドが出てきません

コマンドを持っているのは1号機だけです。1号機がサーバーに入っているか確認してください。入っていても出ない場合は、Discordを再読み込みしてください。

読み上げが始まりません

次の点を確認してください。①自分がVCに入っている ②/joinしたチャンネルで発言している ③BOTにVCへの「接続」「発言」権限がある ④ステージの場合、BOTがスピーカーになっている(挙手していれば、モデレーターが許可する必要があります)。

「空いているBOTがいません」と出ます

そのサーバーにいる号機が、すべて使用中です。2号機以降を招待すると、同時に使えるVCが増えます。/statusで、未招待の号機の招待URLが分かります。

自分の声を変えたい

/voiceで選べます。入力しながらキャラクター名で絞り込めます。速度は/speedです。設定は号機が変わっても引き継がれます。

単語や固有名詞の読み方が違います

/dict addで、単語と読み方を登録してください。そのサーバーの読み上げ全体に反映されます。長い単語が優先され、英字は大文字小文字を区別しません。

名前の読み方が違います

/nameで、ひらがななどの読み方を登録できます。/nameだけを実行すると、表示名に戻ります。

毎回 /join するのが面倒です

サーバーの管理者が/autojoinでオンにすると、誰かがVCに入ったとき、空いている号機が自動で参加します。読み上げ対象は、そのVCのチャットです。AFKチャンネルと、すでに号機がいるVCは対象外です。

別のVCに移したい

先に/leaveで退出させ、移動先のVCに入ってから/joinしてください。

外部連携(Lumi の大喜利など)の使い方は?

サーバーの管理者が、/externalで「オン」を選ぶと、そのサーバー専用のトークン(shb2_で始まる文字列)が、1回だけ表示されます。これを、Lumi のダッシュボードの「読み上げ連携」に貼り付けてください。あとは、読み上げたいチャンネルで号機をVCに入れておく(/joinか/autojoin)と、Lumi が出したお題や回答を、読み上げます。回答は、回答した人本人の声と速度で読みます。トークンを失くしたり、漏らしたりしたときは、/externalの「再生成」で、古いトークンを無効にして、新しく発行できます。やめるときは「オフ」です。

外部連携のトークンは安全ですか

トークンは、サーバーごとに別々で、そのサーバーの読み上げだけを依頼できます。BOT側には、トークンそのものは保存せず、ハッシュ(元に戻せない値)だけを保存します。そのため、BOTの管理者でも、トークンを見ることはできません。認証に失敗するアクセスは、回数を制限しています。

データは保存されますか

保存するのは、設定したユーザーIDごとの声・速度・読み上げ名、サーバー辞書、各サーバーの設定(外部連携のトークンのハッシュを含む)だけです。メッセージの内容は保存しません。ただし、読み上げのため、メッセージの文字列を、音声合成を行うVOICEVOX公開API(open.voicevox.nogame-no.life)に送信します。外部連携APIで、Lumi などから送られてきた文章も、同じように読み上げのためだけにVOICEVOX公開APIに送信し、保存はしません(BOTのログにも、本文は残さず、サーバーIDと件数だけを残します)。

クレジットと注意

  • 音声合成には、VOICEVOXを使用しています。使用する音声ライブラリ・キャラクターごとの利用規約とクレジット表記のルールに従ってください。配信や公開の場で使う場合は、「VOICEVOX:キャラクター名」などのクレジット表記が必要です。
  • 音声合成は、有志が運営する公開API(VOICEVOX Public API Gateway)を利用しています。このBOTは、VOICEVOX公式およびAPIの運営者とは関係ありません。
  • APIには利用上限があります。混雑時などに、読み上げが遅れたり、一時的に止まったりすることがあります。
  • BOTは予告なく、停止・仕様変更をすることがあります。
